# React + TypeScript + Vite
Por favor sigue estas instrucciones para ver este Portfolio correctamente:
Estos comandos tienen que ser copiados en tu terminal
1. Clona el repositorio:
git clone https://github.com/MajoAraujoPiedra/Portfolio.git
2. Abrir la carpeta:
cd portfolio
3. Instala las dependencias:
npm install
4. Correr el proyecto: Esto te va a dar un link el cual podes abrir apretando ctrl cuando lo clickeas, sino usualmente esta es la ruta: http://localhost:5173
npm run dev
